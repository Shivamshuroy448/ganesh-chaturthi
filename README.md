# 🪔 Happy Ganesh Chaturthi 2026 — Virtual Darshan & Motion Puja

An interactive motion website celebrating Ganesh Chaturthi with Lord Ganesha in a sitting posture, offering sacred Panch-Aarti, sweet Modak prasadam, flower showers, and realistic temple bells.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Shivamshuroy448/ganesh-chaturthi)

## 🌸 Features
- **Sitting Lord Ganesha:** Sacred artwork with gentle levitation breathing motion and a rotating 360° divine halo.
- **Transparent Panch-Aarti Diya:** 5-wick brass lamp with carved peacock handle waving organically in a circular aarti motion with synchronized temple bell chimes.
- **Modak Prasadam Offering:** Steaming modak and laddoo thali rising onto the altar with Lord Ganesha's blessing beam.
- **Temple Bell Synthesizer:** Real-time brass bell acoustic synthesis via Web Audio API.
- **Flower Shower:** 60fps canvas physics simulating cascading marigold and hibiscus petals.

## 🚀 Run Locally
```bash
python3 -m http.server 8080
# Open http://localhost:8080 in your browser
```
